# Daymark — To-Do List

A responsive, local-first task manager built with vanilla HTML, CSS, and JavaScript. No build step or dependencies required.

## Run

Open `index.html` in a modern browser, or enable GitHub Pages in the repository settings to publish it.

## Features

- Create, edit, complete, and delete tasks
- Priority levels, categories, due dates, and notes
- Today, Upcoming, Important, Completed, and All Tasks views
- Search and sorting
- Daily progress and task statistics
- Dark/light theme
- Local storage persistence
- Export tasks as JSON
- Responsive layout and reduced-motion support

## Data and privacy

Tasks are stored in the browser's local storage on the device in use. They are not synced between browsers or devices. Use **Export tasks** to create a JSON backup.

## Stack

HTML, CSS, and vanilla JavaScript.
